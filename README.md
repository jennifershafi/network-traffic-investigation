# Network Traffic Investigation

A network security investigation using Wireshark to examine a simulated packet capture and identify unusual outbound network activity.

## Scenario

A workstation was flagged for unusual outbound communication. The objective was to analyze captured network traffic and identify activity that may require further investigation.

## Investigation Areas

- Source and destination IP addresses
- DNS queries
- TCP connections
- Destination ports
- Outbound network activity
- Unusual communication patterns

## Tools Used

- Wireshark
- TCP/IP analysis
- DNS filtering
- Packet inspection

## Evidence

The `evidence` directory contains a synthetic packet capture created for educational and portfolio purposes.

No real organizational or user traffic is included in this project.

## Findings

Findings from the packet capture investigation are documented in `investigation-notes.md`.
